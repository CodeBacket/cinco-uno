# uno-game scaffold

This directory contains the vanilla HTML/CSS/JavaScript implementation target for Cinco UNO.

## Current status

Phase-01 architecture contract is scaffolded:

- `index.html` and `styles.css` app shell
- JS module boundaries in `js/main.js`, `js/engine.js`, `js/ai.js`, `js/ui.js`
- Shared state contract in `js/state.js`

## Local preview

Open `uno-game/index.html` in a browser. The game loop is not yet implemented in this phase.
