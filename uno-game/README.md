# Cinco UNO mini-app scaffold

This folder contains the standalone browser game scaffold for ticket #31.

## Current status

Phase 01 architecture contract is in place:

- HTML shell and setup/game regions in `index.html`
- Base visual scaffolding in `styles.css`
- Module boundaries in `js/main.js`, `js/engine.js`, `js/ai.js`, `js/ui.js`
- Shared constants and state/event contract in `js/state.js`

Later plans in `docs/02` through `docs/05` expand this scaffold with rendering,
engine rules, AI turn logic, and final QA hardening.
