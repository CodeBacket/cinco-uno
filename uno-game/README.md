# uno-game phase-01 scaffold

Phase 01 establishes the architecture contract and module boundaries for Cinco UNO.

## Files

- `index.html`: static shell with menu and play regions.
- `styles.css`: baseline layout styles.
- `js/state.js`: shared state contract constants and helpers.
- `js/engine.js`: engine API boundary stubs (no DOM access).
- `js/ai.js`: AI API boundary stub.
- `js/ui.js`: UI boundary stubs.
- `js/main.js`: bootstrap entrypoint.

## Current status

This scaffold intentionally includes placeholders for phase 02+ implementation work.
